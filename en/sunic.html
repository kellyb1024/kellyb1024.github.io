SUNI C

Web dashboard, campaign scheduling for SK Broadband2026, SK mySUNI future skills program for university students, SUNI C 5th cohort, AI team project, Team lead

Define

SK Broadband has to fit campaigns from many marketing teams within each channel's daily send limit

Requests come in through Google Sheets and one coordinator calculates by hand, so checks and adjustments with marketers go back and forth without end

The problem is not a slow coordinator, but a remaining-capacity table that shows only confirmed requests, so everyone sees a different status

Solution

Remaining send capacity always on the calendar by date, so no need to ask the coordinator

Automatic capacity check the moment a request is made, with 3 alternative dates suggested right away if it doesn't fit

Only checked requests that need adjusting go to the coordinator

Process

In a meeting with the SK Broadband team, heard that "for urgent requests, we write it in the sheet and Slack the coordinator right away," and traced the cause

So we moved the remaining-capacity calculation from people to the screen

User tests with 15 people. Feedback that too many colors were confusing led to a unified palette and remaining capacity by date on the calendar

Result

Top Prize, SUNI C 5th cohort

Dashboard designed to cut the coordinator's steps from request to confirmation from 5 to 1

Plus an adoption kit that takes the team's existing Google Sheets as is

Role

As team lead, led development of the dashboard screens

Led schedules and meetings, taught Claude Code to teammates

Video, presentation

Tool

Claude Code, Adobe Illustrator, Higgsfield
